# Post hoc local Euclidean training on a real language model

2026-09-25. This follow-up is selected after the 18-run trajectory grid: SmolLM2-360M AdamW seed 1 had an observed coefficient-boundary crossing at update 71. Its step-70 state has strict coefficient/weight agreement; a fresh backward replay shows that the current natural-language negative gradient also points toward that coefficient boundary. Selection is disclosed and is not evidence for frequency.

Use exactly that saved, unmodified pre-update state and that update's four WikiText training blocks. No factor interpolation, reverse integration, target modification or new grouping loss. Freeze the same pretrained backbone and selected 12-projection shared bank. Convert the entire model to FP32, disable autocast and TF32, use deterministic evaluation mode. Optimize the fixed mean next-token cross entropy on those actual blocks with vanilla SGD, equal learning rates for bases and logits, no clipping, momentum or weight decay. The fixed batch removes changing-data effects; this is local analysis, not a full data training recipe.

Four predeclared rates .02, .01, .005, .0025, fixed duration .4 (20,40,80,160 steps). Record every exact balanced decision, margin, coefficient old-minus-new score, loss and rank/positivity diagnostics. Save final factors for each step size. Report all four runs, even if no crossing. A fifth zero-learning-rate control lasts 20 steps on the same loss. Compute the initial coefficient-gap differential using autograd and the initial linearized crossing-time prediction. Compare endpoints between adjacent resolutions; these are empirical finite-step convergence diagnostics, not certified numerical integration error bounds.

A successful local reproduction requires initial strict agreement, subsequent strict coefficient disagreement while the weight partition stays unchanged, and positive singular values and routing coefficients throughout. Strictness uses the main trajectory protocol's relative 1e-8 threshold. No claim of general SGD occurrence follows from this selected neighborhood.
