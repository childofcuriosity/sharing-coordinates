# 任务加权响应：分组目标与边界

日期：2026-09-25。独立探索性扩展；不修改现有论文或冻结结果。以下推导延续现有论文的软共享模型与欧氏度量，不作全新核聚类原理的优先权主张。

## 1. 定义任务、测量与动作

有效参数 Θ = A B，A 为 L×K 的 softmax 路由，B 为 K×D 基。固定当前检查点、任务批次分布 P 和已知正学习率 η_B、η_Z、温度 τ。令 G 为该批次平均损失对有效参数的梯度，Y = R_s(G) 为软共享的负有效速度：

    Y_i = η_B Σ_j (a_i · a_j) G_j + (η_Z/τ²) Bᵀ C_i² B G_i,
    C_i = diag(a_i) − a_i a_iᵀ.

行向量/列向量按乘法相应转置。候选分组 H 每行一个 1，每列 m=L/K 个 1；令 C_H=HHᵀ，Q_H=C_H/m。硬共享仅训练组基，沿用相同 η_B，因此 R_H(G)=η_B C_H G。

本文的任务加权目标是 **在软检查点的同一个任务梯度上比较更新**：

    F_P(H) = E_P ||Y − η_B C_H G||_F².

这不是硬共享后重新求梯度的实际更新差，也不是最终任务损失。分组之后在相同有效参数上做组均值 refit，硬模型的起点通常改变，实际梯度也改变；实验必须另外测量损失后果。G 不逐个归一化：大梯度在这个指定目标中确实贡献更多权重。使用未中心化二阶矩，不能把均值项丢掉。

## 2. 精确的分组化简

定义小矩阵 S=E[GGᵀ]、T=sym E[YGᵀ]，sym(X)=(X+Xᵀ)/2，以及 c=E||Y||²。S,T 均为 L×L，不必构造 LD×LD 的响应算子。

**命题 1（任务加权分组目标）。** 对所有平衡 H，

    F_P(H) = c + η_B² m <C_H,S> − 2η_B <C_H,T>
           = c − <C_H,W>,
    W = 2η_B T − η_B² m S.

证明：展开平方；C_H 对称且 C_H²=m C_H，因此硬响应平方项为 η_B² m tr(C_H GGᵀ)，交叉项为 −2η_B tr(C_H GYᵀ)。取期望并利用 C_H 对称即得。对角项固定，因为 (C_H)_ii=1。因此只需最大化同组不同层之间 W_ij 的总和；是否双计 i,j 只影响一个常数倍。

这一般不是对 A 做普通 k-means。W 可不定，甚至含负边；不应错误截断为非负。若要使用核表达，可加足够大的 λI 令 W+λI 半正定，这对所有候选只增加固定 λL。于是仍是平衡图分组/核聚类形式，而非新的一般聚类机制。当前 L=12,K=4 可枚举全部 15,400 个候选，没有局部搜索误差。

只需可观测任务方向 G 和其完整响应 Y 的上述配对矩，就能优化该目标，**不必完整恢复 A,B**。但原来的“仅需响应的非对角块”结论通常不再成立：软响应的对角局部项乘 G_i 后，与其他层 G_j 的相关性进入 T_ij，从而影响分组。即使 AAᵀ 不变，任务加权目标也不能一般丢掉局部响应项。

## 3. 与原来各向同性目标的联系

若 vec(G) 的未中心化二阶矩是 σ²I，则 S=σ² D I，而 T_ij=σ² tr(R_ij)。对 i≠j，有 T_ij=σ² η_B D(AAᵀ)_ij；局部 softmax 项只改变固定的对角贡献。因此 F_P 与原文的 Hilbert–Schmidt 目标只差比例，最优分组回到平衡路由向量聚类。

任务分布一般不满足该条件。即便 Σ=E[vec(G)vec(G)ᵀ] 奇异，F_P 仍良好定义为 tr((R_s−R_H)Σ(R_s−R_H)ᵀ)，但只约束 Σ 所支持的方向。任务上响应相近不能推导全方向算子相近，更不能推导完整因子已被识别。

## 4. 批量梯度不能与单文档梯度混为一谈

设 g_1,…,g_n 是 n 个等长文档块的平均损失梯度，y_i=R_s(g_i)。记单文档经验矩 S_1、T_1、c_1，以及均值 ḡ,ȳ。恢复训练使用 b 个文档块的平均梯度。

**命题 2（有限池内无放回批量）。** 在 n 个记录中均匀无放回取 b≤n 个并取平均时，令 α=(n−b)/(b(n−1))，则精确地

    S_b = α S_1 + (1−α) ḡḡᵀ,
    T_b = α T_1 + (1−α) sym(ȳḡᵀ),
    c_b = α c_1 + (1−α)||ȳ||².

证明：平均梯度外积展开；对角样本项选中概率 b/n，不同样本配对概率 b(b−1)/(n(n−1))。将 Σ_{i≠j} g_i g_jᵀ 写为 n²ḡḡᵀ−nS_1 后化简；交叉矩及响应平方相同。线性 R_s 保证 ȳ 是 ḡ 的响应。

若批次由总体独立有放回抽样，则总体对应系数为 1/b；这是另一个分布，不能和上述有限池系数互换。实验选择池 n=16、b=4，α=1/5；独立评估梯度池 n=32、b=4，α=7/31。二者分别对自己的有限池批次分布精确，既不是 1,820 个独立训练样本，也不声称等于真实训练集的总体分布。作为预定敏感性分析，记录单文档 b=1 目标，不另据其调参。

## 5. 有限样本与实际用途的限制

设 N 为候选分组数，独立同分布批次上每个 F 的单次平方误差均在 [0,M]。Hoeffding 加 N 项 union bound 给出：概率至少 1−δ 时，所有经验目标与总体目标之差不超过 ε=M sqrt(log(2N/δ)/(2n))，经验最优的总体超额风险至多 2ε。证明是经验最优性两侧各加一次 ε。若 ||G||≤g_max 且 ||R_s||op≤r，则可取 M=(r+η_B m)²g_max²。

这只是一个条件性泛化边界，常数可能很松。真实文档可相关，梯度可重尾，模型与数据集曾在历史项目中使用；本次不能直接宣布获得该总体证书，也不能将派生的组合批次当作独立样本放大统计功效。

任务目标优化的是当前更新误差。它可能牺牲初始 refit 损失，也可能在几个更新后失去预测力。尤其 AdamW 引入预条件与状态，本推导不是 AdamW 理论。必须比较：独立数据上的任务响应误差、立即 refit 的 NLL、同预算 SGD 恢复后的 NLL，以及单独标记的 AdamW 实用恢复。无收益、负收益或仅优于随机均不自动支持新增方法有实际价值。
